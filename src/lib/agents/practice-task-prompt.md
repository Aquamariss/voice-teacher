---
skill: practice-task
description: Генерирует практические задачи на применение знаний дисциплины. Кейс-стади или расчётные задачи.
inputs:
  - $discipline_name — название дисциплины
  - $topics_summary   — список тем с названиями
  - $content_sample   — выдержки из учебного контента
  - $complexity       — сложность курса (easy/medium/hard)
  - $has_formulas     — есть ли формулы в контенте (true/false)
output: JSON с массивом из 5 задач
---

Ты составляешь практические задачи для учебного курса. Задачи проверяют умение ПРИМЕНЯТЬ знания — не просто вспомнить факт, а разобраться в реальной ситуации.

## Дисциплина

Название: $discipline_name
Темы курса: $topics_summary
Выдержки из учебного контента:
$content_sample

## Правила генерации

**Формат задач:**
- Если $has_formulas = true: 2–3 задачи типа `calculation` (применение формул с конкретными числами), остальные `case_study`
- Если $has_formulas = false: все задачи типа `case_study`

**Кейс-стади (case_study):**
- Реалистичная ситуация: компания, страна, объект, событие — максимально конкретно
- Данные в задаче: цифры, даты, имена — либо реальные, либо правдоподобные
- Пользователь должен проанализировать ситуацию и описать решение или вывод
- НЕ вопрос с угадыванием — открытый анализ

**Расчётные (calculation):**
- Конкретные числа, которые нужно подставить в формулу
- Задача прикладная: «рассчитай орбиту спутника», «определи силу тяготения», «найди период»
- Данные реалистичные (масса Земли, реальные планеты, типичные инженерные параметры)

**Сложность ($complexity):**
- easy: данные простые, один шаг рассуждения, очевидная связь с теорией
- medium: 2–3 шага, нужно применить несколько концепций
- hard: нетривиальные данные, конфликт факторов, требует глубокого анализа

**Объём:** постановка задачи не более 2000 символов. Включает контекст, данные и чёткий вопрос.

**Эталонный ответ (model_answer):** подробное правильное решение — для автоматической оценки ответов студентов. Включи ключевые пункты, которые должны быть в хорошем ответе. 200–400 слов.

**image_query:** короткий запрос на английском для поиска иллюстрации в Wikipedia (название статьи или явления). Пример: "Kepler's laws of planetary motion", "Orbital mechanics", "Electric circuit".

## Вывод

Выведи строго JSON без комментариев:

```json
{
  "tasks": [
    {
      "task_number": 1,
      "title": "Краткое название задачи",
      "content": "Полная постановка задачи...",
      "task_type": "case_study",
      "model_answer": "Эталонное решение...",
      "image_query": "English Wikipedia article title"
    }
  ]
}
```
