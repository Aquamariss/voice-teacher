# Голосовой учитель — план разработки MVP

## Концепция

Персональное приложение для изучения дисциплин через голосового AI-учителя.
Пользователь создаёт курс, слушает лекции, задаёт вопросы голосом — без рук, как с живым преподавателем.

## Фаза 2 — Голос 🔄 В ПРОЦЕССЕ

### 2.0 Базовый голосовой слой ✅ ГОТОВО

- [x] TTS лекций (ElevenLabs `eleven_turbo_v2_5`, MSE streaming)
- [x] AudioPlayer: стриминг аудио, прогресс-бар, пауза, seek
- [x] AssistantPanel: плавающий чат-ассистент, Claude streaming
- [x] STT голосового ввода (OpenAI Whisper)
- [x] VAD: определение голосовой активности (Web Audio API)
- [x] Голосовой режим: VAD + MediaRecorder + Whisper + ElevenLabs TTS ответов
- [x] Глобальный VoiceContext (провайдер, независимый от панели ассистента)
- [x] VoiceIndicator: кнопка 🎙️ по центру снизу, статус в реальном времени
- [x] Команды лекции: «стоп» → пауза, «продолжи» → возобновить
- [x] Режим лекции: пока лекция играет — VAD принимает только команды, шум игнорируется
- [x] VAD cooldown после команд (защита от эхо-петли)
- [x] busyRef: VAD заблокирован пока ассистент говорит
- [x] Настройка чувствительности микрофона (порог + счётчик кадров)
- [x] В голосовом режиме ассистент отвечает коротко (без markdown)
- [x] Прерывание лекции голосом при начале разговора с ассистентом

### 2.1 Улучшение выбора голоса ⏳ В ОЧЕРЕДИ

Цель: пользователь может выбрать голос учителя и услышать его до начала занятий.

- [ ] Загрузка списка доступных голосов из ElevenLabs API (`/v1/voices`)
- [ ] UI выбора голоса на странице настроек или профиля дисциплины
- [ ] Превью: короткий тестовый фрагмент выбранного голоса прямо в UI
- [ ] Сохранение выбора голоса: глобально (профиль пользователя) и/или per-дисциплина
- [ ] Передача `voice_id` в `/api/tts` из настроек, а не из env-переменной
- [ ] Опционально: настройка скорости речи (`speed` параметр ElevenLabs)

---

### 2.2 Дискуссия после занятия ⏳ В ОЧЕРЕДИ

Цель: после прослушивания лекции учитель сам инициирует короткое обсуждение — проверяет понимание, закрепляет материал.

- [ ] Событие «лекция завершена» (`onEnded` в AudioPlayer) → триггер для ассистента
- [ ] Промпт агента-дискуссанта: задаёт 1–2 открытых вопроса по теме занятия
- [ ] В голосовом режиме: вопрос озвучивается автоматически после паузы ~2 сек
- [ ] В текстовом режиме: вопрос появляется в AssistantPanel
- [ ] Ответ пользователя → ассистент даёт обратную связь, не оценку («интересно, а ещё?»)
- [ ] Итог дискуссии записывается в память дисциплины (см. Фаза 3.2)
- [ ] Кнопка «пропустить обсуждение» — для случаев когда некогда

---

### 2.3 Доработка сквозного чата ⏳ В ОЧЕРЕДИ

Цель: чат с ассистентом работает плавно, не теряет контекст, удобен и в голосе, и в тексте.

- [ ] Сохранение истории чата между страницами (сейчас сбрасывается при переходе)
- [ ] Показ транскрипта голосового ввода в чате (что именно было распознано)
- [ ] Индикация режима лекции в чате: плашка «Лекция на паузе — задавай вопросы»
- [ ] Форматирование ответов ассистента: markdown в тексте, чистая речь в голосе
- [ ] Ограничение длины истории: при переполнении — суммаризация старых сообщений
- [ ] Быстрые действия после занятия: кнопки «Повторить», «Следующее занятие», «Обсудить»
